
# beeline-advisor

Сервис подбора оптимального тарифного плана и дополнительных пакетов для абонентов Билайн на основе детализации потребления за 3 месяца.

## Как это работает

Приложение принимает CSV-файл с детализацией звонков, SMS и интернет-сессий абонента, агрегирует данные по трем расчетным месяцам и подбирает наиболее выгодную комбинацию «Тариф + 0..2 доппакета».

### Ключевая логика и правила расчета

1. **Парсинг и обработка трафика:**
   - Каждый звонок округляется вверх до целой минуты (`math.ceil`) перед суммированием за месяц. Звонки продолжительностью 0 секунд игнорируются (0 минут).
   - Интернет-сессии, пересекающие ночной интервал `[01:00:00, 07:00:00)`, пропорционально разделяются на дневной и ночной трафик на основе времени начала и длительности.
   - Если у тарифа включен ночной безлимит (`night_unlimited = True`), ночной трафик не расходует включенный пакет ГБ.
   - Роуминговые события тарифицируются отдельно по роуминговым ставкам и не списывают базовые пакеты.

2. **Перебор комбинаций и сравнение:**
   - Алгоритм генерирует все сочетания тарифов и наборов доппакетов (до 2 пакетов включительно, допускаются дубли).
   - Все финансовые вычисления выполняются в `Decimal` без промежуточных округлений. Финальные суммы округляются до 0.01 сома по правилу `ROUND_HALF_UP`.

3. **Правило окупаемости смены тарифа (50 сом):**
   - Переход на новый тариф рекомендуется только в том случае, если чистая экономия за 3 месяца превышает разовую стоимость смены тарифа (`monthly_savings * 3 > 50 KGS`).
   - Если экономия за 3 месяца меньше или равна 50 сом, сервис возвращает действие `"stay"`.

4. **Разрешение спорных ситуаций (Tie-breaking):**
   - При равной экономии выбирается вариант с меньшим количеством доппакетов, далее по лексикографическому порядку `tariff_id` и отсортированным `addon_ids`.

## Что сделано

- **Ядро расчетов (`src/calculator.py`, `src/recommender.py`):** реализована математика списаний, перерасхода и правила окупаемости в `Decimal`.
- **Парсер данных (`src/parser.py`):** валидация CSV/JSON, разделение ночного трафика и округление вызовов.
- **Точка входа и CLI (`src/__init__.py`, `main.py`):** функция `recommend(usage_file)` для автопроверки и CLI для быстрой отладки.
- **FastAPI backend (`src/api.py`):** REST API для подключения фронтенда (`POST /api/recommend`).
- **Тестовое покрытие (`tests/`):** юнит-тесты ядра, проверочный прогон по 10 открытым абонентам из `data/` и 12 краевым сценариям из `data/edge_cases/`.
- **Интеграция с веб-интерфейсом:** Streamlit-интерфейс вынесен в отдельный репозиторий. Бэкенд отдает данные для графиков через API (`comparison`), но сам UI в этот репозиторий не запакован.

## Что НЕ сделано (Ограничения и допущения)

- **LLM-генератор объяснений (`src/llm_explainer.py`):** планировали сделать динамическое объяснение выгоды через внешний API LLM. В итоге остановились на детерминированном текстовом шаблоне-фоллбэке, чтобы запуск у жюри не зависел от наличия интернета и API-ключей.
- **Оптимизация под сверхбольшие файлы:** текущий парсер рассчитан на стандартные файлы детализации за 3 месяца. Для промышленных объемов логирования потребовался бы переход на Polars.

## Быстрый запуск

### Требования
- Python 3.11+
- `uv` (рекомендуется) или стандартный `pip`

### 1. Запуск через Python CLI

Запуск расчета по одному абоненту:
```bash
python main.py data/usage_P01.csv
```

Массовый прогон по всем 10 открытым абонентам из папки `data/`:
```bash
python main.py
```

Использование через `uv`:
```bash
uv run python main.py data/usage_P01.csv
```

### 2. Запуск автотестов

```bash
pytest -v
```

### 3. Запуск API-сервера (FastAPI)

```bash
python main.py serve --port 8000
```
Документация Swagger после запуска: `http://localhost:8000/docs`.

### 4. Запуск в Docker

Сборка и запуск контейнера с API:
```bash
docker compose up --build -d
```

Прогон CLI внутри Docker-контейнера:
```bash
docker compose run --rm api python main.py data/usage_P01.csv
```

## Использование как Python-библиотеки

Для программного вызова (контракт ТЗ):

```python
from src import recommend

result = recommend("data/usage_P01.csv")
print(result["recommended_tariff"], result["net_savings_3m"])
```
